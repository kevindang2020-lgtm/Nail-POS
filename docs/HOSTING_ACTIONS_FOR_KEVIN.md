# HOSTING_ACTIONS_FOR_KEVIN.md — what only the account owner can do

Constitution 4 §201 (Definition of Done), BUILD_PLAN Phase 11. Every §201 line whose remaining work is a **hosting
setting** (Railway, AWS, Cloudflare, GitHub, a provider console) is below, with the exact action and how to check it.
The code side of each line is done or listed in the Phase 11 report; nothing here needs a code change. Host of record:
**Railway** (`railway.json`, `railway.worker.json`). The AWS Terraform in `deploy/terraform` is legacy and is not applied.

Order matters: do **A** before go-live, **B** before a second replica, **C** when convenient. Never paste a secret
value into a ticket, chat or this repository — Railway variables and your password manager only.
