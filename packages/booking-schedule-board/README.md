# @aipowersalon/booking-schedule-board

Standalone Booking Schedule Board for the AIPowerSalon POS: Find an opening → technician paging → headers → daily
availability → 15-minute grid → bottom navigation → legend → Block time. Built to merge into the Booking page without
touching Booking Assistant · New Appointment.

- `npm run dev`: demo host on http://localhost:5178
- `npm run check:all`: typecheck, no-print gate, 47 tests, build
- `README-INTEGRATION.md`: host contract, adapter, realtime, decisions
- `MERGE-CHECKLIST.md`: step-by-step merge + acceptance matrix
- `TEST_REPORT.md`: what was verified, and what was not
- `screenshots/`: 1920×1080 renders from the real-browser run
