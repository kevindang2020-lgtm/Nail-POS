## What running it found (all fixed)

Earlier sessions recorded type-checks as "needs CI". Running the full build here showed 4467fb80 **did not build,
could not start, and had broken screens**:

**The API could not start** (three separate causes, each fatal at load):
- `eod-center.controller.ts` imported `@aipowersalon/validation`, a package that does not exist.
- `AiCenterModule`'s decorator referenced `AiFollowUpEscalationJob` before its class declaration (temporal dead zone).
- `@ListQueries` still listed `listFollowUps`, a handler guide 26 retired.

Now `check:boot` → `DI_GRAPH_OK`.

**Gift cards were broken end to end.** `giftScoped` and `giftLocationSql` were `async` functions resolving to Kysely
builders, so every gift-card lookup, payment, reload and issue threw `don't await … directly` before any query ran.
The same defect broke the Customer Notifications list (`searchWhere`). A repo-wide scan for the pattern now finds 0.

**Other runtime defects**
- The legacy communications reply route always answered 503 (the inbox service was never injected).
- `voice-booking.controller` called `ledgerWarn` without importing it.
- Strict request bodies refused fields the server itself reads: `customerDisplayCaptureMode` (Payment Terminals),
  win-back preview `email`/`future`/`minDays`, segment audience-draft `page`/`pageSize`.
- The Owner App Marketing screen crashed on `roi: null` (`null.toFixed`); the contract is now `number | null`, shown as —.
- Super Admin `release-evidence` was unclassified, so it was refused to every platform identity.
- POS: `errorTextOf(e)` without a fallback showed an empty error (always on Vietnamese screens); Notifications and
  Message Templates passed a time zone where `fmtInZone` takes format options; the Copilot and Follow-Ups overlays
  used the UTC date for "today" (wrong every evening after ~8 PM Eastern).
- The generated Owner/Tech error catalogues had unescaped apostrophes (both apps failed to compile); the generator now
  keeps each value's own quotes.
- The customer display rendered a language switch for a language it does not have (English only by Kevin's rule).

**Build / type errors:** 166 in modules, 4 in the API, 54 in the POS — e.g. a `FIX_INPUT` client action not in the
contract (now `NONE`, the registry's convention for input errors), nullable database handles, list-query filter
types (`'string'` → `'text'`, identical at runtime), the reward tender missing from `PaymentMethod`.

**Gates:** `as-any`, module entries (the gate missed `export type {}`), vi-glossary (Kevin's terms: Thợ, hóa đơn,
hàng chờ), inert controls, attack surface, UTC-day idioms, the one lint error, 18 unused lint directives.

**Outdated tests rewritten to the current behavior** (never deleted): the retired receptionist agent/FAQ write routes
are now pinned as retired; the voice read tools include `get_business_info`; the End-of-Day summary test no longer
depends on the date it was written.
