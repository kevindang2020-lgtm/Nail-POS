## B. Genuine gaps found (the real work)

1. **Shared global gateway (the headline violation).** `CheckoutService` was constructed with a single
   `processorFromEnv()` reading global `CARDPOINTE_*` env vars — every tenant shared one merchant. Spec forbids this.
2. **No per-tenant credentials at rest.** `tenant_payment_config` had a `merchant_id` but nowhere for the tenant's
   own gateway username/password/webhook-secret → only the global env credentials existed.
3. **Tenant creation didn't provision payment setup.** `createTenant` made tenant+sub+branch+owner but no
   `tenant_payment_config` row (spec §4).
