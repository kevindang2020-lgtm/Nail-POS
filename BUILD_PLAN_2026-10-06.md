## Working rules for every phase
- The per-document audit in `docs/audit-2026-10-06/` is the checklist; the phase is not done until each line there is DONE
  or recorded as a decision for Kevin with the default taken.
- Fix a bug by first writing the test that fails because of it (unit, PGlite, real-Postgres race, or browser — whichever
  level the bug lives at), then the fix, then the mutation check.
- Reuse, never duplicate: when a parallel implementation is found it is merged behind the canonical one and removed under
  the zero-importer rule, with an expand-then-contract migration if data moves.
- No payment credentials, Twilio/SendGrid keys or outside database logins in the repository, memory or chat.
- Commit per phase (or per coherent unit inside a large phase) with the attribution lines; bundle refreshed after each commit.
